# G1 Motion Studio Guide

User guide for **G1 Motion Studio**, a Windows app from CSIRO Technology for making whole-body motion for the Unitree G1 humanoid in our lab scene: place objects, choose what the robot does to each, and get a 50 Hz motion clip (CSV), an MP4 video and a MuJoCo replay.

Read the guide online: https://ruicsiro.github.io/G1-Motion-Studio-Guide/

The same guide ships with the app, in `Guide\index.html` inside the G1 Motion Studio folder.
