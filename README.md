# G1 Motion Studio Guide

User guide for **G1 Motion Studio**, an app from CSIRO Technology (Windows 10/11 and Linux) for making whole-body motion for the Unitree G1 humanoid in our lab scene: place objects, choose what the robot does to each, and get a 50 Hz motion clip (CSV), an MP4 video, a MuJoCo replay, and a reference motion for Unitree's own `g1_29dof.xml` that a controller can track.

Read the guide online: https://ruicsiro.github.io/G1-Motion-Studio-Guide/

The same guide ships with the app, in `Guide/index.html` inside the G1 Motion Studio folder.
